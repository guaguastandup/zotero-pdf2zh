## 当前只保留的修复

这样错误网页、空文件和明显截断的 PDF 会在导入 Zotero 前报错。
生产代码只新增一行校验；相关测试验证非法内容不会创建临时附件或调用导入，
有效内容仍可导入并清理临时文件。
