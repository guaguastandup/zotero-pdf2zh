## 文件保留与协议

- 每个请求在 `translated/.job-*` 内运行，成功后返回的 PDF 仍使用原有 `/translatedFile/<filename>` 接口。
- 下载文件增加唯一前缀，保留 `.mono.pdf`、`.dual.pdf` 等末尾类型标记。
- 使用同一文件系统内的原子移动，不复制一整份大 PDF。此前已有的输出文件不改写。
- 后处理失败时保留已生成的 PDF 供找回，但任务仍报告失败。保存/清理失败时保留目录并打印位置。
- 用户选择保存的自动术语表 CSV 也会保留；临时上传原文不会冒充翻译结果。
- 无法从已有 PDF 可靠判断原文/译文顺序，直接裁剪已有双语附件时保留其原始页序。
