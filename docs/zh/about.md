# 关于

Zotero PDF2zh 是一个在 Zotero 中使用 PDF2zh 和 PDF2zh_next 进行 PDF 翻译的插件。

## 项目简介

本插件完美保留原文格式，支持多种翻译引擎和服务，让您在 Zotero 中轻松翻译 PDF 文献。

## 核心功能

- 🚀 双引擎支持（PDF2zh 和 PDF2zh_next）
- 📄 完美保留原文格式、公式和排版
- 🔄 多种翻译模式（翻译、裁剪、双语对照等）
- 🌐 支持多种翻译服务（OpenAI、DeepSeek、智谱等）
- ⚙️ 灵活的配置选项
- 🆓 内置免费翻译服务
- 📦 自动更新功能
- 🐳 Docker 部署支持
