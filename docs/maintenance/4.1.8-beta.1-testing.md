## 拉取与本地测试

已有分支：`git fetch origin`，`git switch fix/issue-367-window-menus`，`git pull --ff-only`。

插件在 `plugin/` 执行 `npm ci`、`npm test`、`npm run build`，安装 `build/zotero-pdf-2-zh.xpi` 并重启 Zotero。

服务端先停止原 server，再使用此分支的 `server/` 源码与自己的现有配置启动。已有托管环境可在 server 目录执行 `python update_packages.py --engine all` 后重启；该命令会在现有环境安装/更新依赖。自定义冲突 pin（如 bitstring==5）需移除冲突后再更新。

系统 Python、独立 Windows EXE、外部 Docker 翻译引擎不受托管环境修复覆盖。系统 Python 用户应在实际运行引擎的解释器环境安装 `bitstring>=4.3.0,<5`；不能只在运行 Flask server 的另一个环境中安装。EXE/外部容器需更新其自身运行时。

实机验收：

1. Zotero 11 安装、设置页、单/双主窗口菜单、关闭两个窗口的不同顺序、插件禁用/重新启用。
2. 用 Paper.PDF、Paper.PdF、a.pdf.pdf 测试两个引擎的翻译与附件导入；测试位于 folder.pdf 目录下的原 PDF 裁剪。
3. 旧引擎输入路径包含 pdf2zh_next，确认不会选错环境。
4. 三页测试文件跳过 1 页正常；跳过 3 页或更多有明确错误。
5. 比较/裁剪正常输出；损坏文件或不可写目标不再显示成功。
6. Windows 普通控制台与重定向日志启动分别确认进度/提示。
