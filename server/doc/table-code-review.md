## 修正项

1. 统一新增表格 Python 代码、测试和 fixture 格式，展开压缩语句，改用有名称的局部函数。
2. 不完整命令现在给出明确 `ValueError`，覆盖缺少引擎和 `python -m` 缺少模块两类情况，避免原先可能出现的 `IndexError`；新增回归测试。
3. 环境隔离测试同时 mock PTY 与 Windows inherited-console 路径，修正之前两个 Windows 测试错误。非 Windows 走 `_execute_with_pty`，Windows 走 `_execute_with_inherit`；只 mock 前者会让 Windows 测试启动真实子进程，并且无法捕获用于断言的环境变量。捕获函数改用 `*_dimensions` 接收两条路径不同数量的终端尺寸参数。环境变量断言保持不变，生产执行分支未改变。建议保留此跨平台测试修正；它不改变翻译行为。
4. 测试 bootstrap 必须先隔离缓存再导入引擎，保留该必要初始化顺序，并仅对这份 fixture 显式说明 E402 例外。
